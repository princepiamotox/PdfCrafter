# PdfCrafter

Transform wide smart-board lecture PDFs into printable A4 notes in your browser.

## Features
- Local browser-only PDF processing
- A4 Portrait or Landscape
- Fully custom grid: 1×1 through 8×8 (1–64 slides per A4)
- Separate vertical rows and horizontal columns controls
- Full 16:9 slide is contained without cropping
- Before/After live comparison slider for dark-to-white printable cleanup
- Background cleanup, brightness, contrast, sharpness, grayscale, invert, page numbers
- Remove unwanted pages
- Multiple PDFs
- Live A4 sheet preview
- PDF export
- No login, ads, watermark or server upload

## GitHub Pages
Upload all files to the repository root and enable **Settings → Pages → Deploy from a branch → main → /(root)**.
